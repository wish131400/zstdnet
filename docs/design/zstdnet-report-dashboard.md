# ZstdNet 本地流量报告设计

## 目标

ZstdNet 服务端负责采集并持久化启用 Zstd 的游戏 TCP 连接流量；已安装模组的客户端通过游戏网络请求固定结构的统计数据，在本地生成一个不依赖 CDN、HTTP 服务或公共上传站点的自包含 HTML 报告。

## 用户流程

1. 管理员或有权限的玩家执行 `/zstdreport today|session|24h|7d|30d`。
2. 服务端校验权限并返回所选时间范围的聚合报告。
3. 客户端把内置 HTML/CSS/JS 模板与报告 JSON 合成为单个 HTML 文件。
4. 聊天栏显示可点击的“打开统计面板”和文件位置。
5. 点击后由客户端操作系统默认浏览器打开本地文件。

默认输出：

```text
.minecraft/config/zstdnet/reports/<server-id>/latest.html
.minecraft/config/zstdnet/reports/<server-id>/zstdnet-report-YYYYMMDD-HHmmss-SSS.html
```

客户端按连接的服务器地址隔离报告目录，每台服务器最多保留最近 10 份归档报告；`latest.html` 是该服务器最新报告的固定入口，不计入归档上限。无法归属服务器的单人游戏报告写入独立的 `singleplayer` 目录。旧版直接写在 `reports/` 根目录下的报告不会自动迁移。

## 数据口径

- 所有方向均采用服务端视角：`ingress` 为客户端到服务端，`egress` 为服务端到客户端。
- `wire` 表示 Zstd 帧的应用层字节：出站在压缩帧生成时计数，入站在完整帧解码时计数。出站可能尚在发送队列中，不等同于公网网卡或 FRP 的实时测速，也不包含 IP/TCP 头、ACK 与重传。
- `raw` 表示进入压缩器之前或离开解压器之后的原始 Minecraft 数据，用于计算节省量。
- 当前架构只统计启用 Zstd 的游戏 TCP 连接。UDP 字段为兼容历史统计数据而保留，ZstdNet 不接管或统计其他模组的 UDP 连接。
- HUD 显示服务端所有 Zstd 连接的合计，连接数表示当前启用 Zstd 的连接数。累计总量在服务端启动时清零，玩家断线不清零。
- 每日与运行期平均速率统一使用 `字节数 / 实际经过秒数`，不对已有平均值再次平均。

## 生命周期与存储

- 一次“运行期”从 Minecraft `ServerStarted` 开始，到 `ServerStopping` 结束。
- PROXY v2 和 `debug` 配置在服务端启动时应用，修改后重启生效。`debug` 只控制转发成功日志，不影响统计计数。
- 工作线程只更新内存计数；统计服务按固定周期采样、聚合和原子持久化。
- 主要存储位于服务端 `config/zstdnet/stats/`：

```text
state-v1.json        # 当前运行与恢复状态
daily/YYYY-MM-DD.json
runs/<run-id>.json
```

## 报告协议

报告使用有版本号的 JSON 文档，顶层固定包含：

```json
{
  "schemaVersion": 1,
  "range": "today",
  "generatedAt": 0,
  "server": {},
  "summary": {},
  "series": [],
  "daily": [],
  "runs": []
}
```

短时间范围使用 5 分钟桶，30 天范围使用 1 小时桶。单次响应限制为约 1 MiB 和 2500 个聚合点；服务端绝不发送 HTML、脚本或客户端文件路径。

## 面板布局

- 顶部摘要：今日总流量、本次运行总流量、当前查询平均上下行和压缩节省量。
- 顶部服务器标识只显示客户端实际连接地址，不重复显示固定的 LAN 运行模式。
- 主图：服务端 ingress/egress 时间序列。所有报告提供全部、1 小时、6 小时、12 小时和自定义范围；30 天报告额外提供 1 天和 7 天。
- 入站与出站颜色由当前主题色预设决定，每套预设使用具有明显色相差和足够文字对比度的颜色组合，不依赖固定蓝/橙说明。
- 次级分析：原始/线路流量、压缩节省、TCP/UDP 占比、P95/P99 与峰值。
- 带宽参考同时显示二进制字节速率（`KiB/s`）和十进制线路速率（`Mbps`），换算公式为 `bytes/s × 8 ÷ 1,000,000`。
- 历史：每日流量和最近运行记录。
- 前端使用原生 HTML/CSS/JS 与 Canvas/SVG，模板完全内嵌，不加载远程字体、脚本或图片。

## 视觉与主题

- 支持深色和浅色模式，模式与主题色选择保存在浏览器本地存储中。
- 内置 10 套主题色：默认、暖砂、极简黑白、暗夜、玫瑰花园、湖光、日落霞光、森林低语、海风、薰衣草梦。
- 主题色按钮依次循环预设，并在提示信息中显示当前主题和下一套主题。
- 卡片环境光使用超出卡片边界的透明缓冲层，动画移动时不会露出伪元素裁切边缘。
- 下载按钮使用近纯黑背景、白色文字和固定珊瑚橙铁砧图标；悬停时图标移动到按钮几何中心并放大。
- `prefers-reduced-motion` 启用时关闭非必要动画。

视觉概念见 `zstdnet-report-dashboard-concept.png`。
